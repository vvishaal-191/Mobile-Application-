# Emergere Mobile Application

An HRMS mobile application built with React Native and HTML preview interface.

## Features
- Manager Hub & Employee Dashboard
- Leave Approvals & Permission Approvals
- Team Attendance & My Attendance Tracking
- Holiday Calendar
- Profile Management
- Notifications

## Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation & Preview
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development preview server:
   ```bash
   npm start
   ```
   Or run Expo:
   ```bash
   npm run expo:lan
   ```
